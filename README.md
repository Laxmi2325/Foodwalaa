# Foodwala – Food Ordering Web Application

Foodwala is a Java-based food ordering web application that allows users to browse restaurants, explore food menus, manage their cart, and place orders.

## Technologies Used

- **Backend:** Core Java, Advanced Java, JSP, Servlets
- **Frontend:** HTML, CSS, JavaScript
- **Database:** MySQL
- **Database Connectivity:** JDBC
- **Architecture:** MVC (Model–View–Controller)
- **Server:** Apache Tomcat 10.1
- **Development Tools:** Eclipse IDE, MySQL Workbench, Git, GitHub

## Features

- User registration and login
- Restaurant listing and menu browsing
- Add-to-cart and quantity management
- Checkout and order processing
- Order confirmation and order details
- Database integration using JDBC

## Project Structure

- `src/main/java` – Java model classes, DAO classes, and controllers
- `src/main/webapp` – JSP pages, images, and web resources
- `WEB-INF` – Web application configuration and libraries

## Setup Requirements

1. Install JDK, Eclipse IDE, Apache Tomcat 10.1, and MySQL.
2. Clone or download this repository.
3. Create the required MySQL database and tables.
4. Configure the database connection using your local credentials.
5. Import the project into Eclipse and configure Tomcat.
6. Run the application on the local server.
